KiCad‑iOS · The Editors

Every tool is the real tool.

Each editor is KiCad's own module — the same code that ships on the desktop — loaded inside the one app process and opened as its own window from the project manager's launcher.

✓Project Manager

The home window: the real menu bar (File / Edit / View / Tools / Preferences), the Project Files tree, the launcher column with the real colour icons, and the tool description pane — in KiCad's light desktop appearance. Audited control by control: every menu opens, every item acts, every button does its real job. Confirmed standing on device from v10 on.

✓Schematic Editor

Full schematic capture on the Cairo software canvas. It opens and draws on device — symbols, wires, the sheet. Pinch zoom and two-finger pan, titlebar chrome, and no OpenGL attempt anywhere: the canvas is Cairo from the first pixel.

✓PCB Editor

Board layout with the same canvas machinery as the schematic side — footprint placement, routing, zones, DRC. It opens and works, a first-class citizen: the same pinch zoom, pan, titlebar and keyboard support as the Schematic Editor.

Symbol Editor

Create and edit schematic symbols against the bundled symbol libraries — all 222 of them ride in the bundle, with the default tables resolving straight to them.

Footprint Editor

Create and edit footprints against the 155 bundled footprint libraries. The PCM addons from the official index — the PCBWay plug-in and the JLCPCB Fabrication Toolkit — ship in the bundle too, each with its own license.

CvPcb

Footprint assignment: match every symbol in the schematic to its footprint from the bundled libraries.

Gerber Viewer

KiCad's Gerber viewer opens inside the app — on the desktop it launched as a separate program; here it is a window in the same process, like every other tool.

PCB Calculator

The calculator tools ship and open in-app, alongside the rest of the manager's launcher column.

Image Converter

Bitmap2Component opens inside the app and turns images into schematic symbols and PCB footprints.

Drawing Sheet Editor

The page-layout editor for title blocks and sheet templates, in-app like the rest — and its canvas gets the same no-OpenGL guarantee as the two main editors.

/ Stated plainly

The 3D viewer does not work on iOS

KiCad's 3D viewer renders through OpenGL, and iOS has no OpenGL. The port leaves it that way rather than faking a viewport: the 3D viewer does not work, and everything else — the 2D editors, the manager, the companion tools — is unaffected. It is the port's one standing functional limitation, and it is named wherever the tool list appears.
