KiCad‑iOS · Unofficial Port · V1

KiCad runs on iPad. The real KiCad.

This is a port of the actual upstream KiCad 10.0.1 — its own source code, its own windows, its own buttons — compiled for iPadOS. Not a recreation. Not a lookalike. V1.1 is the current release — V1, the first official release after fifteen Spike builds, plus the structural fresh-install fix its device pass called for. On a real iPad it installs, completes KiCad's first-run wizard, and opens the KiCad project manager; projects create and open in the shared Documents folder, and the Schematic Editor draws on the software canvas — each of those confirmed on hardware in the Spike passes. V1 rebuilds the window chrome around a real titlebar, brings pinch zoom to both editors, fits every window to the display, and fixes the defects those passes found. The 3D viewer remains OpenGL-bound and does not work on iOS; the 2D editors are unaffected.

/ What this is

KiCad is the world's leading open-source electronics design suite — schematic capture, PCB layout, and a family of companion tools driven from one project manager. It ships on Windows, macOS and Linux. Now it runs on the iPad too. Launch the app and KiCad's project manager stands up: the real menu bar, the Project Files tree, the launcher column with the real colour icons, and the tool descriptions — in KiCad's light desktop appearance, driven by touch, Apple Pencil, keyboard and mouse.

/ Proven on a real iPad

These are not gate results — each one is an on-device pass on real hardware during the Spike rounds.

✓The launch chain

Install → sign → launch → Python initialises → the first-run wizard completes → the project manager stands. Every link demonstrated on hardware (v10).

✓Startup, clean

v13's on-device pass found the manager standing with no editor-load error — the root-cause fix for the broken early builds holds on hardware at startup.

✓Projects create and open

v14's pass created and opened projects under the Documents default — files live in the app's shared Documents folder and move on and off the iPad the normal way.

✓Editors open and work

v14's pass: the editors open and work. v15's pass went further — the Schematic Editor opens and draws on the Cairo software canvas, no crash. That pass is also where V1's work list came from; the V1 page answers it item by item.

✓Stock libraries in the box

KiCad 10.0.1's libraries ship complete inside the bundle — 222 symbol libraries and 155 footprint libraries, plus 19 project templates and the demo projects — with the default library tables resolving straight to them, proven by the build gates.

✓Python is in

KiCad's embedded Python ships whole: the CPython standard library, the compiled pcbnew module, stock scripting plugins and footprint wizards, plus the PCBWay and JLCPCB addons from the official PCM index.

/ New in V1

V1 is verified in the shipped binary by the release gates — the gates read the shipped executable itself and fail on the previous release on every V1 count. V1's on-device pass runs next; the release page keeps the two kinds of evidence labelled.

Titlebar window controls

Every window carries a real titlebar strip — title on the left, Minimize and Close on the right, the menu bar directly below it in the editors. Drag the strip and the window follows. No more floating pill.

Pinch zoom, both editors

Two-finger pinch zooms at the pinch centre through KiCad's own view machinery, and a two-finger drag pans — in the Schematic Editor and the PCB Editor. Display & input has the details.

Every window fits

Windows open filling the screen at natural scale, and every dialog is clamped to the display it is actually on — its size is asked from the display at runtime, never hardcoded. Preferences and the setup dialogs keep their buttons on screen.

The found defects, fixed

The occasional OpenGL failure dialog is gone at the root — the canvas factory itself returns Cairo. The manager's "schema file" error is fixed: the schemas ship. And a crash that killed fresh installs on first launch is fixed in the window toolkit.
