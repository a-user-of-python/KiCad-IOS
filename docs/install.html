KiCad‑iOS · Install

Sideload it. Launch it. It's KiCad.

Builds ship as an unsigned .ipa (≈263 MB — the complete stock libraries ride along). The install is a standard sideload.

  1. Download the KiCad-V1.ipa — the release build from the repository. (Workflow artifacts from the Spike workflow are the same unsigned package.)
  2. Sideload it with a signer such as Signulous, or your own signing setup.
  3. Launch KiCad. The first-run wizard walks through setup, and the project manager opens behind it.

Requirements: an M‑series iPad running iPadOS 17 or later.

/ Fresh install or upgrade — both are first-class

Upgrading over an earlier build keeps your projects and settings; V1's fixes are written to survive inherited state — frames maximise regardless of geometry older builds persisted, and the library tables are repaired at startup if an early broken build left them chained to a bogus location. A fresh install is a tested path too: pre-release testing caught a crash that killed a fresh install 0.44 s into its first launch — first-run library preload re-entering the status bar while its fields were half-built — and V1 fixes it at the toolkit layer, verified in the shipped binary. Delete the app, reinstall, and the first launch reaches the manager.

/ Your files

File sharing is on. Projects live in the app's Documents folder — the folder the Files app and a connected computer see — and move on and off the iPad the normal way. New projects default to that folder. The app's own choosers and lists work over the same shared folder.
